# Slice Merchant Tools

Tools for prospecting and pitching Charlotte merchants on lower credit-card processing fees.

## Files

### rate_calculator.csv
Open in Excel or Google Sheets. Yellow / input cells = monthly volume, current blended rate, signed rate, proposed rate. Everything else calculates live (monthly/annual cost, gap, savings).

### outreach_tracker.csv
Log every email you send. Columns cover date, business, contact, vertical, volume estimate, response status, meeting date, notes, and pipeline status.

**How to use the tracker**
1. Open the CSV in Google Sheets or Excel.
2. Add one row per prospect the same day you send.
3. Update Response Status and Notes the moment a reply comes in.
4. Status values: New → Contacted → Meeting Booked → Proposal Sent → Closed Won / Closed Lost / Do Not Contact.

Keep the tracker updated and you will quickly see which verticals and subject lines convert.
